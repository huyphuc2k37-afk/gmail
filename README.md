# Gmail signup QR code investigation

Workspace này dùng để điều tra tại sao Google hiển thị QR code bắt buộc quét bằng điện thoại khi đăng ký Gmail.

## Mục đích
- Quan sát flow đăng ký Gmail tại https://accounts.google.com/signup
- Ghi nhận URL, text, screenshot tại bước Google hiển thị QR
- Phân tích nguyên nhân trigger QR (IP, fingerprint, region, behavior, v.v.)
